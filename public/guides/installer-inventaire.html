Installer l’application Inventaire All Vap’s

Ce n’est pas une appli du Play Store / App Store : c’est une application web installable (plein écran) depuis le navigateur.

Adresse inventaire
Ouvrez d’abord la page inventaire dans Chrome (Android/Samsung) ou Safari (iPhone), puis suivez les étapes ci-dessous.

Android / Samsung (Chrome)

  1. Ouvrez la page /inventaire dans Chrome.
  2. Appuyez sur le menu ⋮ en haut à droite.
  3. Choisissez « Installer l’application » ou « Ajouter à l’écran d’accueil ».
  4. Confirmez. Une icône Inventaire apparaît sur l’écran d’accueil.

iPhone / iPad (Safari uniquement)

  1. Ouvrez la page /inventaire dans Safari (pas Chrome).
  2. Touchez le bouton Partager (carré avec flèche vers le haut).
  3. Faites défiler et choisissez « Sur l’écran d’accueil ».
  4. Validez Ajouter. Lancez l’icône comme une app.

Astuces

  • Restez connecté au Wi-Fi / 4G de la boutique.
  • Autorisez la caméra quand le navigateur le demande (scan + flash).
  • Si l’écran reste blanc : fermez l’onglet, rouvrez l’icône installée.
