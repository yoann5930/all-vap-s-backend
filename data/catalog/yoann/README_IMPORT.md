# All Vap's — Catalogue e-liquides

Ce dossier contient une première base cumulative, dédoublonnée et structurée pour Cursor.

## Fichiers

- `allvaps_catalogue.json` : fabricants, gammes, produits et formats connus.
- `prompt_cursor_import.txt` : consignes prêtes à copier dans Cursor.
- `audit_report.md` : état de l'audit et points restant à vérifier.

## Important

Cette version est une base de travail auditée, mais elle n'est pas encore déclarée exhaustive. Les gammes dont le tableau `products` est vide doivent être complétées depuis les catalogues officiels avant mise en production.

Aucun doublon ne doit être créé lors des prochains ajouts. La clé de rapprochement doit utiliser les noms normalisés et les alias présents dans le JSON.
